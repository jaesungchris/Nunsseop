Under the hood

How now playing works재생 정보를 읽는 방법

Since macOS 15.4, the private MediaRemote framework only answers apps signed by Apple. Nunsseop runs a tiny helper inside the system's /usr/bin/perl to read what's playing and send play, pause, skip and seek.

macOS 15.4부터 비공개 MediaRemote 프레임워크는 Apple이 서명한 앱에만 응답합니다. Nunsseop은 시스템의 /usr/bin/perl 안에서 작은 헬퍼를 실행해 재생 정보를 읽고 재생·일시정지·건너뛰기·위치 이동을 보냅니다.

If a future macOS update blocks it, Nunsseop falls back to AppleScript for Music and Spotify and to reading media tabs in browsers.

이후 macOS 업데이트로 막히면 Music·Spotify는 AppleScript로, 브라우저는 미디어 탭 읽기로 자동 전환됩니다.

No personal data is collected or sent. Network use is limited to a daily release check, lyrics from LRCLIB, weather from Open-Meteo for the city you choose, and fallback artwork — each can be turned off. AI usage is read from files Claude Code and Codex already keep on your Mac.

개인 정보는 수집하거나 전송하지 않습니다. 네트워크는 하루 한 번 새 버전 확인, LRCLIB 가사, 지정한 도시의 Open-Meteo 날씨, 대체 경로의 앨범아트에만 쓰며 모두 끌 수 있습니다. AI 사용량은 Claude Code와 Codex가 이 Mac에 이미 남기는 파일에서 읽습니다.

FAQ

Good questions.

자주 묻는 질문.

Is it really free?정말 무료인가요?
Yes. Free, open source under the MIT license, with no account, subscription or trial.
네. MIT 라이선스의 오픈소스이고, 계정·구독·체험 기간이 없습니다.
My Mac doesn't have a notch. Does it work?노치가 없는 Mac에서도 되나요?
Yes. On a screen without a notch, Nunsseop shows a small pill at the top centre that opens the same way. You can choose which display it appears on.
네. 노치가 없는 화면에서는 위쪽 가운데에 작은 알약 모양으로 나타나고, 똑같이 열립니다. 어느 화면에 띄울지도 고를 수 있어요.
macOS says the app can't be opened."앱을 열 수 없습니다"라고 나와요.
The app isn't notarized yet. Install with Homebrew, which handles this for you, or run xattr -dr com.apple.quarantine /Applications/Nunsseop.app once after copying it from the dmg.
아직 공증되지 않은 앱이라 그렇습니다. Homebrew로 설치하면 알아서 처리되고, dmg로 설치했다면 xattr -dr com.apple.quarantine /Applications/Nunsseop.app을 한 번 실행하세요.
Nothing shows up when I play music.음악을 틀어도 아무것도 안 나와요.
Nunsseop reads whatever macOS lists as Now Playing, so the player has to report to Control Center. Most apps and browsers do. If a future macOS update blocks this, Nunsseop asks for Automation access and falls back to AppleScript for Music, Spotify and browsers.
Nunsseop은 macOS가 '지금 재생 중'으로 아는 것을 읽습니다. 그래서 제어 센터에 재생 정보가 뜨는 앱이어야 하는데, 대부분의 앱과 브라우저가 그렇습니다. 이후 macOS 업데이트로 막히면 자동화 권한을 받아 Music, Spotify, 브라우저를 AppleScript로 읽습니다.
Can Search replace Spotlight or Raycast?Spotlight나 Raycast 대신 쓸 수 있나요?
That's the idea. It finds apps, files, commands, settings, clipboard entries, emoji and sums, and learns what you open most. To put it on ⌘Space, record that shortcut in Settings › Services and Nunsseop will take you to Keyboard Shortcuts to switch Spotlight's off.
그걸 목표로 만들었습니다. 앱, 파일, 명령, 설정, 클립보드, 이모지, 계산을 찾고, 자주 여는 것을 먼저 보여 줍니다. ⌘Space로 쓰려면 설정 › 서비스에서 그 단축키를 녹화하세요. Spotlight 단축키를 끌 수 있도록 키보드 단축키 화면으로 안내합니다.
There are too many tabs for me.탭이 너무 많아요.
Right-click the notch, open Settings › Notch, and switch off what you don't need. Turned-off features stop running, so they cost nothing.
노치를 우클릭해 설정 › 노치에서 필요 없는 탭을 끄세요. 꺼 둔 기능은 아예 동작하지 않아서 자원도 쓰지 않습니다.
Does AI usage need my login?AI 사용량을 보려면 로그인이 필요한가요?
No. It reads files Claude Code and Codex already keep on your Mac, and sends nothing anywhere. Claude's limits come from the oh-my-claudecode HUD cache when you have it; otherwise you see recent token use.
아니요. Claude Code와 Codex가 이 Mac에 이미 남기는 파일만 읽고, 어디로도 보내지 않습니다. Claude 한도는 oh-my-claudecode HUD가 있으면 그 캐시에서 읽고, 없으면 최근 토큰 사용량을 보여 줍니다.
Will it slow my Mac down?Mac이 느려지지 않나요?
It's a small native app that mostly sleeps. Stats, usage and similar tabs refresh only while they're open.
대부분 쉬고 있는 작은 네이티브 앱입니다. 시스템 상태나 사용량 같은 탭은 열려 있을 때만 새로 읽어요.
